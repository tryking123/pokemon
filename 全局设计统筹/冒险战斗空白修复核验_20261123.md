# 冒险战斗空白修复核验

日期：2026-11-23（北京时间）。适用纯离线普通冒险 C3037 / Battle.view.view_start，修复版本 adventure-description-type-20261123-v1。

## 问题与证据

用户存档下一关 11210（显示第 1210 关），此前 1209 关连续，地图 70017、角色阶段 2、默认队六只上阵精灵均满足要求。最近尝试为 FLED，不构成 ACTIVE 互斥。原存档完整解析，未修改。

当前源码独立重建包在 64 位隔离环境实际点击冒险，复现默认胖丁头像、白色背景及双方空阵位。诊断 Event.AddListener 后捕获 Battle.view.view_start 内 auraSlots 异常：attempt to compare number with string，定位 local-team-talents.lua 原第 18 行 row.description > 0。原数据管理器会将 description 文案编号就地转换为已本地化的说明文本。此前裸表夹具只使用编号，未覆盖这一流程。旧验收包 32 位正常不能说明仅有 64 位受影响：根因是补丁对本地化字段类型的错误假设。

## 修复与兼容

仅修改全队天赋配对时对说明字段的有效性判断：接受正数编号或非空说明文本，并以原值参与相同说明、条件和动作的配对键。空值及空文本不配对。保持原天赋效果、数值、配对条件、来源刷新及离场清理规则；不新增协议字段或迁移存档。

C3037 开场、C3001 胜利回执及事务结算均保持既有契约。不会通过修改玩家进度或跳关掩盖故障。未修改服务端。
